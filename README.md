# 📊 easyTrader · 股神模拟器

> 一个基于 Python 的 A 股量化分析系统，集成 **评分**、**回测**、**估值**、**复盘** 四大核心模块，提供图形化操作界面。
>
> 版本：2026.06.26 · 数据来源：东方财富 / 申万指数 (akshare)

---

## 快速开始

### 环境要求
- Python 3.11+
- MySQL 5.7+ **（推荐）** 或 SQLite

### 安装依赖
```bash
pip install -r requirements.txt
```

### 初始化行业数据（首次使用）
```python
from trader.valuation.industry import download_sw_industry
download_sw_industry()
```

### 启动 GUI
```bash
python trader/gui_app.py
```

## 四大模块

### 一、股神评分

| 评分体系 | 核心理念 | 评分维度 | 适用场景 |
|---------|---------|---------|---------|
| 🥇 巴菲特价值评分 | 优质公司 + 合理价格 | ROE/利润率/负债率(50分) + 趋势(30分) + PE估值(20分) | 长期价值投资，寻找优质白马 |
| 🥇 格雷厄姆评分 | 安全边际，低估值 | PE(30分) + PB(25分) + 盈利稳定(15分) + 财务安全(20分) + 流动比率(10分) | 寻找低估、高安全边际的价值股 |
| 🥇 徐翔趋势评分 | 趋势 + 量价配合 | 价格动量(25分) + 成交量放大(25分) + 连涨天数(20分) + 突破新高(20分) + 波动稳定(10分) | 短线/波段交易，追强势股 |
| 🥇 Renoyuan 核心评分 | 综合财务+增长+估值+股息 | 质量(30分) + 增长(25分) + 估值(20分) + 稳定性(15分) + 股息率(10分) | 综合型选股，兼顾质量与价格 |
| 🥇 方老哥筹码趋势评分 | 中线锁仓+首板突破 | 筹码集中度(20分) + 获利盘(15分) + 主力资金(15分) + 大单活跃度(10分) + 动量(15分) + 成交量(10分) + 突破形态(10分) + 趋势稳定(5分) | 中线重仓 / 首板博弈 / 筹码分析 |
| 🥇 徐彬财务安全评分 | 资产负债+现金流覆盖 | 资产负债结构 + 现金流覆盖分析 | 财务风控筛选 |

**评分分值体系：** 每项 0~100 分，含对应评级（A+/A/B+/B/C/D）

**市场扫描：** 支持一键扫描全市场或指定板块（上证A股、深证A股、创业板、科创板、北交所），可多评分体系交叉评估。

### 二、量化回测

基于历史 K 线数据，按指定评分策略模拟交易，输出收益曲线与统计指标。

**支持策略：**
- 各评分体系独立作为选股策略
- 自定义多因子组合

**回测参数：**
- 回测周期（起始/结束日期）
- 初始资金
- 评分阈值（买入/卖出分界线）
- 持仓上限

**输出指标：**
- 累计收益率
- 年化收益率
- 最大回撤
- 夏普比率
- 胜率 / 盈亏比
- 交易次数统计

> 左侧面板点击「执行回测」→ 自动填入当前选中股票 → 切换到回测标签页 → 确认参数后点击「开始回测」

---

### 三、估值分析

| 方法 | 核心公式 | 依赖数据 |
|-----|---------|---------|
| 📐 PE估值法 | 行业合理PE × EPS | 行业PE区间、每股收益 |
| 📐 PB估值法 | 行业合理PB × BVPS | 行业PB区间、每股净资产 |
| 📐 PS估值法 | 行业PS × 营收/总股本 | 营收、总股本 |
| 📐 PEG估值法 | 合理PE = 增长率（PEG=1） | EPS、净利润增长率 |

**输出结果：**
- 各方法合理股价与置信区间
- 当前股价偏离度（%）
- 综合判断：低估 / 偏低 / 合理 / 偏高 / 高估

> 左侧面板点击「估值分析」→ 自动填入当前选中股票 → 切换到估值标签页 → 选择估值方法 → 点击「开始估值」

### 四、股神复盘

| 复盘类型 | 功能说明 |
|---------|---------|
| 📈 市场复盘 | 四大指数表现（上证/深证/创业板/科创板）+ 市场情绪指标 + 个股涨跌TOP3（近一周/近三月） |
| 📋 个股复盘 | 输入股票代码 → 拉取近一年K线 → 各区间涨跌幅（昨日/近周/近两月/近六月/近一年）+ 关键财报数据 + DeepSeek AI 智能分析 |
| 🏭 行业复盘 | 申万行业分类 → 市值排名TOP5 + 热度排名（昨日/近一月/近一年涨跌幅TOP5） |
