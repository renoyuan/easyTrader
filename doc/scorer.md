# Scorer 打分模型文档

> 记录 `trader/scorer/` 目录下所有评分模型的建模规则与评分逻辑。

---

## 1. 巴菲特评分 (`buffett.py`)

**核心思想**：价值投资（财务质地 + 趋势 + 估值），满分 100 分。

### 评分结构

| 维度 | 分值 | 说明 |
|------|------|------|
| 财务基础分 | 0~50 | 核心财务指标绝对值打分 |
| 趋势得分 | 0~30 | 各指标的年际变化趋势 |
| 估值分（PE历史分位） | 0~20 | 近5年 PE 历史百分位 |
| **总分** | **0~100** | 质地趋势封顶 80 + 估值 20 |

### 财务基础分（Base Score）

各项指标取**多年平均值**，满足条件则得分：

| 指标 | 条件 | 得分 |
|------|------|------|
| **ROE（净资产收益率）** | ≥ 15% | 14 |
| | ≥ 10% | 9 |
| | ≥ 5% | 4 |
| **净利润率** | ≥ 15% | 10 |
| | ≥ 8% | 6 |
| | ≥ 3% | 2 |
| **资产负债率** | < 40% | 10 |
| | < 60% | 6 |
| **经营现金流/净利润** | ≥ 0.8 | 10 |
| | ≥ 0.5 | 6 |
| **净利润增长率** | > 10% | 10 |
| | > 0% | 5 |

### 趋势得分（Trend Score）

每个指标计算线性回归斜率，根据方向给分：

| 指标 | 满分 | 逻辑 |
|------|------|------|
| ROE 趋势 | 8 | 斜率 > 0 → 满分；斜率 ≈ 0 → 70%分；下降 → 0 |
| 净利润率趋势 | 6 | 同上 |
| 经营现金流/净利润趋势 | 6 | 同上 |
| 资产负债率趋势（反向） | 4 | 斜率 < 0（负债率下降）→ 满分 |
| 净利润增长率趋势 | 6 | 斜率 > 0 → 满分 |

趋势总分 ≥ 25 → "上升"；≥ 18 → "平稳"；否则 → "下降"

### 估值分（Valuation Score）

基于近5年 PE(TTM) 历史百分位：

| PE 百分位 | 得分 | 标签 |
|-----------|------|------|
| < 30% | 20 | 低估 ✅ |
| 30% ~ 60% | 10 | 合理 ⚖️ |
| 60% ~ 80% | 5 | 偏高 ⚠️ |
| > 80% | 0 | 高估 ❌ |

### 综合评级

| 总分 | 评级 |
|------|------|
| ≥ 80 | ✅ 卓越标的（长期持有） |
| 65 ~ 79 | ✅ 优质公司 |
| 50 ~ 64 | ⚠️ 一般 |
| < 50 | ❌ 回避 |

## 2. 格雷厄姆评分 (`graham.py`)

**核心思想**：安全边际（低估值 + 财务安全 + 盈利稳定），满分 100 分。

### 评分结构

| 维度 | 分值 | 说明 |
|------|------|------|
| PE 估值 | 0~30 | 当前 PE 绝对值打分 |
| PB 估值 | 0~25 | 当前 PB 绝对值打分 |
| 盈利稳定性 | 0~15 | 多年净利润为正的比率 |
| 资产负债率 | 0~20 | 负债越低分越高 |
| 流动比率 | 0~10 | 流动比率越高越好 |
| **总分** | **0~100** | 封顶 100 |

### 各项评分规则

**① PE（核心指标）**
| PE | 得分 |
|----|------|
| < 10 | 30 |
| 10 ~ 15 | 20 |
| 15 ~ 25 | 10 |
| ≥ 25 | 0 |

**② PB**
| PB | 得分 |
|----|------|
| < 1.0 | 25 |
| 1.0 ~ 1.5 | 15 |
| 1.5 ~ 2.0 | 5 |
| ≥ 2.0 | 0 |

**③ 盈利稳定性**
- 多年净利润增长率 > 0 的比率
- 比率 > 80% → 15分；> 60% → 8分

**④ 资产负债率**
- < 30% → 20分
- 30% ~ 50% → 10分
- ≥ 50% → 0分

**⑤ 流动比率**
- > 1.5 → 10分
- 1.0 ~ 1.5 → 5分
- < 1.0 → 0分

### 综合评级

| 总分 | 评级 |
|------|------|
| ≥ 80 | 🔥 深度低估（格雷厄姆机会） |
| 60 ~ 79 | ✅ 价值股 |
| 40 ~ 59 | ⚠️ 普通 |
| < 40 | ❌ 高估 |

## 3. 徐翔风格评分 (`xuxiang.py`)

**核心思想**：短期趋势交易（动量 + 成交量 + 情绪），满分 100 分。

> 只看 K 线行情，不看基本面。

### 评分结构

| 维度 | 分值 | 说明 |
|------|------|------|
| 价格动量 | 0~25 | 10日涨幅 |
| 成交量放大 | 0~25 | 近10日量比 |
| 连续上涨天数 | 0~20 | 最近5日上涨天数 |
| 近1年新高突破 | 0~20 | 当前价是否为近1年最高 |
| 波动率 | 0~10 | 日波动率 < 2% 加分 |
| **总分** | **0~100** | 封顶 100 |

### 各项评分规则

**① 价格动量（10日）**
| 涨幅 | 得分 |
|------|------|
| > 15% | 25 |
| > 8% | 15 |
| > 3% | 8 |
| ≤ 3% | 0 |

**② 成交量放大**
| 量比（近10日均值） | 得分 |
|---------------------|------|
| > 3倍 | 25 |
| > 2倍 | 15 |
| > 1.5倍 | 8 |
| ≤ 1.5倍 | 0 |

**③ 连续上涨**
| 最近5日上涨天数 | 得分 |
|------------------|------|
| ≥ 4天 | 20 |
| ≥ 3天 | 10 |
| < 3天 | 0 |

**④ 新高突破**
- 当前收盘价是近1年最高价 → 20分

**⑤ 波动率**
- 日收益率标准差 < 0.02 → 10分

### 综合评级

| 总分 | 评级 |
|------|------|
| ≥ 80 | 🔥 强势龙头（可参与） |
| 60 ~ 79 | ⚡ 中等趋势（观察） |
| 40 ~ 59 | ⚠️ 弱势震荡 |
| < 40 | ❌ 无交易价值 |

## 数据源说明

所有评分模型统一通过 `trader/processor/feature.py` 的 `StockFeatureProcessor` 获取财务指标，
该处理器依赖 `trader/data/statement.py` 的 `StatementDownload` 数据抽象层。

- 估值数据（PE/PB）通过 `akshare.stock_value_em` 实时获取
- K 线行情通过 `StatementDownload.get_kline_df()` 获取（优先本地数据库，缺失自动补拉）
